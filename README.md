# UI Automation Framework

A robust, scalable UI Automation Framework built with **Java**, **Selenium WebDriver**, **TestNG**, and **ExtentReports**. Designed using the Page Object Model (POM) and includes reusable components such as WaitHelper, Screenshot Utility, and RetryAnalyzer.

---

## 🚀 Features

- 🔍 **Page Object Model (POM)**
- ✅ **TestNG** test runner
- 📸 **Screenshots on Failure**
- 🌐 **WaitHelper** with retry and JS support
- 📊 **Extent HTML Reports** with custom step logging
- 🔁 **RetryAnalyzer** for flaky test re-execution
- ⚙️ Easy CI/CD integration support
